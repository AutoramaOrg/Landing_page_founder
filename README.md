# Autorama Racing - Landing Page

Landing page em React + Vite + Tailwind para os Pacotes de Fundador do jogo Autorama Racing, com uma página de patrocinadores em `/patrocinadores/`.

## Rodar localmente

```bash
npm install
npm run dev
```

O projeto abre em `http://127.0.0.1:5173/`. A página de patrocinadores fica em `http://127.0.0.1:5173/patrocinadores/`.

## Build

```bash
npm run build
```
